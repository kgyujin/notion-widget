# 🧩 Notion Widgets Collection

Notion 페이지를 더욱 풍성하고 유용하게 만들어주는 위젯 모음집입니다.
각 위젯은 **서버리스(Serverless)** 환경에서 동작하며, 사용자가 직접 배포하거나 제공된 링크를 통해 간편하게 사용할 수 있도록 설계되었습니다.

---

## 📂 위젯 목록 (Widgets)

### 1. 📚 [도서 검색 & 기록 위젯 (Book Search)](./book-search)
독서 기록을 위한 필수 아이템! Notion을 나만의 서재로 만들어보세요.
*   **기능**: 알라딘 DB 기반 도서 검색, Notion 데이터베이스 원클릭 저장
*   **특징**:
    *   📖 책 표지, 저자, 출판사 정보 자동 입력
    *   🎨 5가지 컬러 테마 지원 (Mint, Pink, Blue, Purple, Gray)
    *   🔒 민감 정보(Token) 브라우저 로컬 저장으로 보안 강화
    *   📱 모바일/PC 반응형 디자인

### 2. ⏳ [카운트다운 위젯 (Countdown)](./countdown)
중요한 일정이나 목표일까지 남은 시간을 직관적으로 보여줍니다.
*   **기능**: D-Day 카운트다운, 시각적 진행률 표시
*   **특징**:
    *   ⚡ 가볍고 빠른 HTML/JS 기반
    *   📅 목표 날짜 설정 가능
    *   🖼️ 깔끔하고 미니멀한 디자인
