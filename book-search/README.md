# 📚 Notion Book Search Widget

Notion 독서 노트에 사용할 수 있는 **똑똑하고 예쁜 도서 검색 위젯**입니다.  
책 제목을 검색하고 추가 버튼만 누르면, 내 Notion 데이터베이스에 책 정보가 깔끔하게 정리되어 들어갑니다.

<br/>

## ✨ 주요 기능

| 기능 | 설명 |
| :--- | :--- |
| **🔍 스마트 검색** | 알라딘 도서 DB 기반의 고화질 표지와 정확한 정보 제공 |
| **📑 중복 방지** | 이미 등록된 책은 '덮어쓰기'로 깔끔하게 정보만 업데이트 |
| **📱 멀티 디바이스** | **어디서나 연동 주소**를 사용하면 폰, 태블릿, PC 어디서든 설정 유지 |
| **🎨 테마 & 태그** | 5가지 컬러 테마 지원 및 장르/저자/출판사 자동 태깅 |

## 🚀 시작하기

### 1단계: Notion API 준비
내 Notion에 글을 쓸 수 있는 '열쇠'를 만드는 과정입니다.

1. [Notion 내 통합 만들기](https://www.notion.so/my-integrations) 페이지 접속
2. `+ 새 통합` 클릭 → 이름 입력(예: `독서 기록장`) → 제출
3. **시크릿 토큰**(`secret_...`으로 시작)을 복사해두세요.

### 2단계: 데이터베이스 연결
책을 저장할 Notion 데이터베이스에 권한을 줍니다.

1. 책을 저장할 Notion 데이터베이스 페이지 열기
2. 우측 상단 `...` 메뉴 → `연결(Connect)` → 방금 만든 통합 이름 검색 및 선택
3. `확인` 클릭

### 3단계: 위젯 설정 (중요! ⭐)
1. 위젯 화면에서 ⚙️ **설정 아이콘** 클릭
2. **연결 정보 입력**:
    *   **Notion Token**: 아까 복사한 시크릿 토큰 붙여넣기
    *   **Database ID**: 데이터베이스 URL의 32자리 ID 복사 붙여넣기
        *   *(URL 예시: notion.so/user/**`1a2b3c...`**?v=...)*
3. **속성 매핑**: 내 DB의 컬럼 이름과 정확히 일치시켜주세요. (제목, 저자, 출판사, 장르, 표지 등)
4. **주소 복사**:
    > **💡 꿀팁**: **`🌍 어디서나 연동 (추천)`** 버튼을 누르세요!
    > 이 버튼으로 복사한 주소는 설정을 포함하고 있어서, **아이폰, 갤럭시, 다른 PC 어디서든** 설정을 다시 할 필요 없이 바로 작동합니다.

### 4단계: Notion에 심기 (Embed)
1. Notion 페이지에서 `/embed` 또는 `/임베드` 입력
2. 복사한 URL 붙여넣기
3. 위젯의 가장자리를 드래그해서 원하는 크기로 조절하세요.

## ❓ 자주 묻는 질문

### Q. 핸드폰에서 보면 설정이 풀려요.
**'기본 주소'** 대신 **'🌍 어디서나 연동'** 버튼으로 주소를 복사해서 사용하세요. 보안을 위해 기본적으로는 브라우저에만 설정을 저장하지만, 연동 주소를 쓰면 주소 자체에 암호화된 설정이 포함되어 기기를 가리지 않습니다.

### Q. '이미 등록된 도서'라고 떠요.
중복된 책이 감지되면 알림창이 뜹니다. **'덮어쓰기'**를 누르면, 내가 써둔 독서 감상평이나 다른 내용은 그대로 두고 **책 제목, 저자, 표지 등의 기본 정보만 최신으로 업데이트**해줍니다.

### Q. 표지 이미지가 안 들어가요.
Notion 데이터베이스의 표지 속성 타입을 **'파일 및 미디어(Files & Media)'** 또는 **'URL'**로 설정해주셔야 합니다. 텍스트 속성이라면 URL 주소 글자만 들어갑니다.
